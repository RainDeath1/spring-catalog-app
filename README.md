# Spring Catalog App

Простое веб-приложение на Spring Boot для отображения каталога книг.

## Используемые технологии

- Java 21
- Spring Boot
- Spring Web
- Thymeleaf
- Maven

## Функциональность

Приложение отображает список книг со следующими полями:

- ID
- Название
- Автор
- Год издания

Данные хранятся в статическом списке внутри контроллера.

## Запуск

Запустить приложение через класс:

`SpringCatalogAppApplication`

После запуска открыть в браузере:

`http://localhost:8080`

## Структура проекта

- `Book` — модель книги
- `CatalogController` — контроллер каталога
- `catalog.html` — Thymeleaf-шаблон
